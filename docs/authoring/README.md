# Authoring guide

Read these before adding or changing a skill.

- [skill-anatomy.md](skill-anatomy.md): folder shape, frontmatter, body, prose, host-neutral wording.
- [subagent-roles.md](subagent-roles.md): how a skill hands part of its work to a fresh subagent without host-specific agent files.
- [scripts.md](scripts.md): when and how to bundle scripts.
- [layout-and-install.md](layout-and-install.md): repo layout, adding a skill, install paths.

Check your change with `python3 scripts/validate-skills.py`.
